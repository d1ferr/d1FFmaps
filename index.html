Privacy Policy

d1FFmaps · updated 22 September 2026

Who and what

This policy covers the browser extension d1FFmaps — a lobby analyzer for FACEIT CS2 (the "Extension"), developed and maintained by d1FF (the "Developer").

In short

The Extension does not collect, store remotely, or share any user data with third parties. It has no backend server, no analytics, and no telemetry.

What data is processed

  • FACEIT Data API key — entered by the user, stored in chrome.storage.local inside their browser, and used only as an authorization header for requests to https://open.faceit.com. The Developer never receives it and has no access to it.
  • FACEIT nickname — entered by the user, stored in the same place, used only so that win probabilities are shown for the user's own team.
  • Model settings — numeric coefficients, stored in the same place.
  • Public player statistics of the match — requested from the FACEIT Data API when a match page is opened, displayed on screen and kept in memory for no longer than the browser session. Nothing is written to disk.

Where requests go

The only external endpoint is https://open.faceit.com (the official FACEIT Data API). The Extension makes no other network requests. Processing on the FACEIT side is governed by FACEIT's own privacy policy.

What the Extension does not do

  • does not read or transmit browsing history, page content, cookies, or clipboard;
  • does not display ads and does not modify links;
  • does not sell or share data with third parties;
  • does not load or execute remotely hosted code.

Permissions and why they are needed

  • storage — keep the key, nickname and settings inside the browser.
  • activeTab — when the toolbar icon is clicked, read the address of the open match page to extract the match identifier.
  • Host access to https://open.faceit.com/* — request public statistics.
  • Content script on https://www.faceit.com/* — render the analysis panel on the match page.

Storage and security

  • All data stays on the user's device, in the browser's own extension storage (chrome.storage.local). The Extension has no server, so there is nothing to transmit or store remotely.
  • The FACEIT API key is stored in plain text, the same way the browser stores any other extension setting. It is not additionally encrypted, because a browser extension has nowhere to keep a decryption key that an attacker with access to the same profile could not read as well — such encryption would look like protection without being one. Anyone with access to the browser profile or to the device can therefore read the key.
  • The key in question is a Server side FACEIT Data API key, issued to the user by FACEIT. It grants read-only access to public FACEIT statistics. It does not control the user's FACEIT account, cannot change anything there, and carries no payment or identity capability.
  • Requests to https://open.faceit.com are made over HTTPS only. The key travels in the Authorization header; redirects are refused, so the key cannot be forwarded to another host. Cookies are not attached to these requests.
  • Recommended practice: use a key created specifically for this Extension, and revoke it at developers.faceit.com if the device is lost or shared. The options page has a "Delete key" button that removes it from browser storage immediately.

Retention

The key, nickname and settings are kept until the user deletes them or removes the Extension — there is no expiry, because there is no server-side copy to expire. Match statistics live only in memory while the browser session lasts and are never written to disk.

Data deletion

The user can delete all Extension data at any time, without contacting the Developer:

  • Delete the API key — open the Extension options and press "Удалить ключ" (Delete key). The key is removed from chrome.storage.local immediately.
  • Delete the nickname and settings — clear the corresponding fields on the same page and save.
  • Delete everything at once — remove the Extension in the browser (chrome://extensions → Remove). The browser wipes its entire storage.
  • Revoke the key on FACEIT's side — delete the key or the app at developers.faceit.com.

There is nothing to request from the Developer: no copies of user data exist on the Developer's side, because the data never leaves the browser.

Children

The Extension is not directed to children under 13 and does not knowingly collect any data from them — just as it collects no data from any other user.

Changes

If a future version starts collecting any data, this page will be updated, the collection will be optional, and it will be described in the store listing before the update ships.

Политика конфиденциальности

d1FFmaps · обновлено 22 сентября 2026

Кто и что

Эта политика относится к расширению браузера d1FFmaps — анализатор лобби FACEIT CS2 («Расширение»), которое разрабатывает и поддерживает d1FF («Разработчик»).

Коротко

Расширение не собирает, не хранит на стороне и не передаёт третьим лицам никакие данные пользователя. У расширения нет собственного сервера, аналитики и телеметрии.

Какие данные обрабатываются

  • Ключ FACEIT Data API — вводится пользователем, хранится в chrome.storage.local внутри его браузера и используется только как заголовок авторизации при запросах к https://open.faceit.com. Разработчику ключ не передаётся и ему недоступен.
  • Никнейм FACEIT — вводится пользователем, хранится там же, нужен лишь для того, чтобы проценты в отчёте считались за его команду.
  • Настройки расчёта — числовые коэффициенты модели, хранятся там же.
  • Публичная статистика игроков матча — запрашивается у FACEIT Data API в момент открытия страницы матча, показывается на экране и держится в оперативной памяти не дольше сессии браузера. На диск не записывается.

Куда уходят запросы

Единственный внешний адрес — https://open.faceit.com (официальный Data API FACEIT). Других сетевых обращений расширение не делает. Обработка данных на стороне FACEIT регулируется политикой конфиденциальности FACEIT.

Чего расширение не делает

  • не читает и не передаёт историю просмотров, содержимое страниц, куки и буфер обмена;
  • не показывает рекламу и не подменяет ссылки;
  • не продаёт и не передаёт данные третьим лицам;
  • не загружает и не выполняет код с внешних серверов.

Разрешения и зачем они

  • storage — сохранить ключ, ник и настройки внутри браузера.
  • activeTab — при нажатии на иконку узнать адрес открытой страницы матча, чтобы извлечь из него идентификатор матча.
  • Доступ к https://open.faceit.com/* — запрос публичной статистики.
  • Скрипт на страницах https://www.faceit.com/* — отрисовка панели с анализом на странице матча.

Хранение и безопасность

  • Все данные остаются на устройстве пользователя, в собственном хранилище расширения (chrome.storage.local). Сервера у Расширения нет, поэтому передавать и хранить что-либо удалённо не требуется.
  • Ключ FACEIT API хранится открытым текстом — так же, как браузер хранит любую другую настройку расширения. Дополнительно он не шифруется: расширению негде держать ключ расшифровки так, чтобы его не прочитал тот, у кого есть доступ к тому же профилю браузера. Такое шифрование выглядело бы защитой, не являясь ею. Поэтому любой, у кого есть доступ к профилю браузера или к устройству, может прочитать ключ.
  • Речь идёт о ключе Server side FACEIT Data API, который пользователь получает у FACEIT. Он даёт доступ только на чтение публичной статистики FACEIT: он не управляет аккаунтом пользователя, ничего в нём не меняет и не связан с платежами или подтверждением личности.
  • Запросы к https://open.faceit.com идут только по HTTPS. Ключ передаётся в заголовке Authorization; переадресации запрещены, поэтому ключ не может уйти на чужой хост. Куки к этим запросам не прикрепляются.
  • Рекомендация: заведите отдельный ключ именно для этого Расширения и отзовите его на developers.faceit.com, если устройство потеряно или им пользуется кто-то ещё. Кнопка «Удалить ключ» на странице настроек убирает его из хранилища браузера немедленно.

Сроки хранения

Ключ, ник и настройки хранятся до тех пор, пока пользователь их не удалит или не удалит Расширение: срока давности нет, потому что нет и серверной копии, которую нужно было бы удалять. Статистика матча живёт только в оперативной памяти в течение сессии браузера и на диск не записывается.

Удаление данных

Пользователь в любой момент может удалить все данные Расширения самостоятельно, без обращения к Разработчику:

  • Удалить ключ API — открыть настройки Расширения и нажать «Удалить ключ». Ключ немедленно стирается из chrome.storage.local.
  • Удалить ник и настройки расчёта — очистить соответствующие поля на той же странице и сохранить.
  • Удалить всё сразу — удалить Расширение в браузере (chrome://extensions → «Удалить»). Браузер стирает всё его хранилище.
  • Отозвать ключ на стороне FACEIT — в личном кабинете developers.faceit.com удалить ключ или приложение.

Запрашивать удаление данных у Разработчика не нужно и не у чего: копий данных пользователя у Разработчика нет — они не покидают браузер.

Дети

Расширение не предназначено для детей младше 13 лет и не собирает от них никаких данных осознанно — как и от любых других пользователей.

Изменения

Если в будущей версии появится сбор каких-либо данных, эта страница будет обновлена, а сбор будет отключаемым и описан в карточке расширения до обновления.
